- 결정 사항:
  - Penpot처럼 좌표는 절대값으로 유지하고, 순서는 부모의 `children` 배열, 회전·기울임은 `transform` 행렬로 분리했다. `transform`은 아직 모두 단위 행렬이고 렌더링에 쓰지 않는다(3단계에서 가져오기·렌더 연결).
  - undo 기록은 문서 사본 대신 Transaction(변경과 역변경)을 저장한다. 같은 도형의 같은 속성 편집이 1초 안에 이어지면 하나로 합친다. undo 직후의 편집은 합치지 않는다.
  - 파일 열기와 `.fig` 가져오기는 `setDocument` 변경으로 표현해 되돌릴 수 있게 했다.
  - `figmaImport.ts`가 `model`의 런타임 함수를 쓰게 되어 Node의 타입 제거 실행(CLI)이 확장자 없는 import를 찾지 못했다. `./model.ts`로 바꾸고 `allowImportingTsExtensions`를 켰다.
  - 자동 저장 키 이름(`canvas-studio-v1`)은 유지했다. 기존 사용자 저장본을 그대로 읽어 변환하기 위해서다.

  - 프레임 크기를 바꾸면 자식은 그대로 두고(Figma 기본 제약), 그룹 크기를 바꾸면 자식을 같은 비율로 늘린다. 속성 패널에서 프레임 X·Y를 바꾸면 자식도 함께 옮긴다(이전에는 프레임만 움직이던 문제).
