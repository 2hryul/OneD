# VNPL Figma 파일 관찰 기록

관찰일: 2026-11-17. [제공된 파일과 선택 노드](https://www.figma.com/design/REDACTED).

## 접근 및 화면

- Chrome의 로그인된 세션에서 파일을 보기 권한으로 열었다. 상단에 **편집 권한 요청**이 표시됐으므로 생성·이동·수정 동작은 이 파일에서 시험하지 않았다.
- 왼쪽은 `Guide`, `Page` 페이지와 계층형 레이어 목록이다. 오른쪽 속성 패널은 선택한 요소의 Auto Layout 흐름, 크기, 패딩, 간격, 색상 및 내보내기 설정을 보여준다.
- 선택된 `Contents` 프레임의 크기는 1,200×2,143px이다. 세로 Auto Layout, 상단 패딩 50px, 하단 패딩 120px, 간격 80px로 표시됐다.
- 같은 화면의 `GNB+`는 컴포넌트 인스턴스이며 가로 1,920px 채우기, 세로 132px 허그로 표시됐다.

## 로컬 `.fig` 구조

Figma의 **파일 → 로컬 복사본 저장**으로 받은 파일을 로컬에서 [openfig-core](https://github.com/OpenFig-org/openfig-core)로 파싱했다. 원본 파일은 Git에 포함하지 않는다.

| 항목 | 관찰값 |
|---|---:|
| 전체 노드 | 20,709 |
| 포함 이미지 | 126 |
| 선택 노드 `779:23219`의 직접·간접 하위 노드 | 103 |
| 선택 노드 아래 인스턴스 | 27 |
| 선택 노드 아래 텍스트 | 20 |
| 선택 노드 아래 프레임 | 51 |

`Contents`의 자식은 `Breadcrumb` 인스턴스와 `con` 프레임이다. 프레임 안에는 `img`, `table` 등 중첩 프레임이 있다. 인스턴스는 컴포넌트 정의를 GUID로 참조하며 다수의 텍스트·스타일 override를 보유한다.

## 구현에 반영한 점과 남은 차이

- `.fig` 파일에서 링크의 노드 ID로 원하는 프레임을 선택하고 계층, 위치, 크기, 솔리드 색상, 텍스트와 기본 글꼴 값을 가져온다. 인스턴스의 컴포넌트 정의를 하위 요소로 펼치고 `overrideKey`가 일치하는 override를 적용한다.
- 선택 노드의 변환 결과는 227개 요소, 펼친 인스턴스 45개, 적용한 override 54개, 미적용 override 38개다. SVG 경로로 복원하지 못한 도형 20개는 근사 처리한다.
- 이미지·그라디언트와 정확한 Auto Layout 렌더링은 남아 있다. 내보낸 TSX는 현재 고정 좌표 초안이다.
- 다음 검증에서는 `Contents` 프레임의 렌더링 결과를 원본과 비교하고, 남은 38개 override의 대상과 효과를 확인해야 한다. 편집 기능 동등성 검증에는 편집 가능한 별도 Figma 파일이 필요하다.
